# 客诉预警风险详情表格化实施计划

> 本计划替代此前的折叠列表实现，仅调整客诉预警页右侧学生风险详情区域。

## 目标

将风险事件改为标准 Ant Design 表格，每条事件固定占一行；完整信息通过独立详情抽屉查看，并保留命中关键词、状态操作、证据聊天和顶部学生基本信息。

## 实施任务

- [x] 更新组件测试，覆盖七列表格、排序、筛选、分页、详情抽屉与状态操作。
- [x] 将日期分组事件扁平化为组件内部表格行，保持同日事件原顺序并按日期倒序展示。
- [x] 移除 `Collapse`、展开状态和日期分组展示，接入固定列、内部横向滚动和每页 10 条分页。
- [x] 新增风险事件详情抽屉，直接展示完整摘要、关键词、建议、审计信息和证据列表。
- [x] 保留二级完整聊天抽屉与待处理事件的“更多操作”。
- [x] 切换学生或状态筛选时重置页码并关闭事件详情。
- [x] 在表格中补充“命中关键词”列，完整关键词可直接扫描或悬停查看。
- [x] 将风险等级与风险类型统计从学生基本信息区移动到风险表格上方。
- [x] 更新客诉预警端到端流程，覆盖表格、详情抽屉、状态更新和窄屏溢出。
- [x] 运行相关组件测试、全量单元测试、类型检查、生产构建和风险详情端到端测试。

## 验收标准

- 表格包含风险日期、风险类型、风险等级、风险总结、命中关键词、处理状态、证据数和操作八列。
- 风险总结最多两行，悬停可查看完整内容；等级和状态使用语义化标签。
- 待处理事件可从操作列完成“标记为已处理”与“排除风险”，终态事件只保留详情。
- 详情抽屉不包含折叠面板，并可继续打开完整聊天抽屉。
- 单页隐藏分页，超过 10 条可翻页；学生或筛选变化后回到第一页。
- 页面和右侧详情容器不横向溢出，窄屏仅表格内部滚动。
