# 单学生客诉预警原型

该原型实现：

- 高/中/低/数据不足四档客诉风险规则；
- 30天服务观察窗口、最近3个月成绩趋势和全周期历史客诉；
- 顾问、学管、规划师、质检四种角色的证据权限和建议动作；
- 风险概览、关键证据、时间线、处理动作与待核实项；
- 人工核实、生成待办、升级和误报反馈交互。

## 运行

```bash
cd complaint-risk-demo
npm test
npm run serve
```

浏览器打开 `http://localhost:4173`。

## 核心接口

`evaluateComplaintRisk(student, role)` 返回统一的风险回答结构：

- `risk`：等级、趋势、状态和免责声明；
- `completeness`：关键数据完整度；
- `evidence`：按角色权限裁剪后的前5条证据；
- `timeline`：最近3—5条关键事件；
- `actions`：按角色和时效生成的处理动作；
- `verificationItems`：必须人工确认的不确定事项。

示例数据只用于原型展示，接入业务系统时应替换为真实工作台、企微、电话外呼和质检记录。
